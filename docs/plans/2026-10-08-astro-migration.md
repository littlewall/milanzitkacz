# Dokončení migrace do Astro

Cíl: zachovat původní obsah a vzhled, dokončit české i anglické statické stránky a odstranit zbytky nefunkčního přepisu.

1. Opravit importy CSS modulů a typy pro Astro a React.
2. Generovat všech osm stránek také pod `/en/`, včetně přepínače jazyka a SEO odkazů.
3. Obnovit portfolio textů s modálním zobrazením, sociální odkazy a registraci audio přehrávače.
4. Zahrnout přesunuté veřejné soubory do Gitu, opravit neexistující interní odkazy a aktualizovat příkazy a README.
5. Ověřit typecheck, produkční build, všechny lokální odkazy a funkce v prohlížeči.
